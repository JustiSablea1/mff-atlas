# MFF Atlas

Русскоязычное PWA для планирования развития аккаунта Marvel Future Fight. Открывается в Safari и устанавливается через «Поделиться» → «На экран Домой».

[Открыть MFF Atlas](https://justisablea1.github.io/mff-atlas/)

- JSON из версий 1.x и 2.x. Приложение показывает предпросмотр, объединяет записи и сохраняет текущие значения при конфликте. Восстановление требует подтверждения. Перед записью IndexedDB сохраняет предыдущий профиль в той же транзакции.
- Альбомные скриншоты стандартного ростера из восьми столбцов. Atlas сопоставляет портреты локально и предлагает кандидатов на проверку. Для других экранов доступен OCR; зависимости и модели загружаются с jsDelivr, изображение обрабатывается на устройстве.
- Каталог на основе THANO$VIB$ 12.3.5 и объявленных Netmarble персонажей War of Kings. План использует датированные примеры сборок, ввод игрока и совместимость CTP. Дата проверки источников отображается в приложении. Состав каталога и рекомендации обновляются отдельно.

## Разработка

Без сборки. Запуск из корня репозитория:

```sh
python3 -m http.server 8765
node --test tests/*.test.mjs
```

GitHub Pages публикует корень `main`. При выпуске новой версии меняй ключ кеша в `sw.js` и путь к папке ресурсов релиза одновременно с обновлением версии в `index.html`. Service worker устанавливает оболочку целиком перед активацией. Кеши хранят только публичные ресурсы. Перенос из ключа `mff-atlas-v12` создаёт копию старого профиля и сохраняет исходный ключ. Индекс портретов можно пересобрать через `scripts/portrait-index.py` из соответствующего экспорта каталога и архива портретов THANO$VIB$.

Установленный профиль и локальная история могут быть удалены вместе с данными Safari или приложения. Сохраняй резервный JSON отдельно. Личные профили и скриншоты хранятся вне репозитория.
